# chilmark-assets

Static images for the Chilmark Real Estate Services website (chilmarkre.com),
served to Squarespace Code Blocks via jsDelivr CDN.

**Usage:** `https://cdn.jsdelivr.net/gh/ShindeCRE/chilmark-assets@main/<path>`
e.g. `.../@main/images/properties/225-brae-blvd.jpg`

This repo must stay **public** — jsDelivr will not serve from a private repo.

## ⚠️ Images pending replacement
Everything under `images/gen/`, `images/generated/`, `images/cinematic/` and
`images/premium/` is AI-generated at ~1MP and upscaled. It is placeholder only
and is being replaced with real photography. Do not treat these as photographs
of real buildings.

`images/properties/` (Crexi + drone), `images/listings/` and `images/team/`
are real and should be kept.
